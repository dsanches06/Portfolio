Tema Visual / Conceito

Design moderno e minimalista: paleta de alto contraste, tipografia legível e espaçamento generoso para melhor leitura. Interface focada no conteúdo e na usabilidade.

1. Paleta: alto contraste (ex.: #1a1a1a sobre #ffffff). 

:root {
  --text-primary: #1a1a1a;  /* 19:1 contraste */
  --bg-primary: #ffffff;
  --text-secondary: #334155;
  --bg-secondary: #f1f5f9;
}
body { color: var(--text-primary); background: var(--bg-primary); }

2. Tipografia: Poppins (corpo) e Fira Code (técnico).

3. Responsividade: mobile-first com breakpoints em 768px+.

Validação HTML5 + Mensagens JS Customizadas:

<!-- HTML com validação -->
<form id="contactForm" novalidate>
  <input type="text" name="nome" 
         required minlength="3">
  <input type="email" name="email" 
         required>

           required minlength="10"></textarea>

<!-- JS: Validação customizada -->
const form = document.getElementById('contactForm');
const feedback = document.getElementById('mensagem');

form.addEventListener('submit', (e) => {
  e.preventDefault();
  
  if (form.checkValidity()) {
    feedback.textContent = '✓ Mensagem enviada!';
    feedback.className = 'feedback success';
    form.reset();
  } else {
    feedback.textContent = '✗ Preencha todos';
    feedback.className = 'feedback error';
  }
});

  position: fixed;
  bottom: 30px;
  right: 30px;
  opacity: 0;
  visibility: hidden;
  transition: 0.3s;

  opacity: 1;
  visibility: visible;
}

<!-- JS: Scroll suave -->
const backBtn = document.getElementById('backToTop');

window.addEventListener('scroll', () => {
  if (window.scrollY > 300) {
    backBtn.classList.add('show');
  } else {
    backBtn.classList.remove('show');
  }
});

backBtn.addEventListener('click', () => {
  window.scrollTo({
    top: 0,
    behavior: 'smooth'
  });
});

Principal Desafio Técnico

Alcançar um nível elevado de acessibilidade (WCAG AA/AAA) mantendo um design moderno e responsivo — em particular:

  • Contraste de cores suficiente para texto e componentes.
  • Ordem lógica de foco e navegação por teclado.
  • Touch targets e usabilidade em ecrãs pequenos.
Desafio

Solução Implementada

Foram aplicadas várias medidas práticas:

  • Paleta de alto contraste: revisão de cores para obter ≥7:1 em textos principais.
  • ARIA e landmarks: uso de `nav`, `main`, `header`, `footer` e `aria-labels` para leitores de tela.
  • Gerência de foco: scripts para retorno do foco ao fechar menus e outlines visíveis com `:focus`.
  • Touch targets: botões e links com `min-height`/`min-width` apropriados e espaçamento touch-friendly.
  • Progressive enhancement: funcionalidade básica sem JS, melhorada com scripts para animações e UX.

Resultado: interface acessível, testada em teclado, leitores de ecrã e múltiplos ecrãs.
